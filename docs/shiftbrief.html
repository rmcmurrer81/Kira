Getting started

A local workspace.
A simple start.

Download the installer, review the release notes, and open ShiftBrief from the Start menu. Python is included; a separate Python installation is not required.

The initial installer is unsigned. Review its source and published checksums before running it. Do not bypass security checks merely because a website tells you to.

Install and open

Use the Windows installer above. A Desktop shortcut is optional. Your browser opens the local app; the new workspace starts blank. Select “Open example” to explore the fictional demo.

Use records without AI

Normal Records mode needs no model, account or API key. Optional model integration uses your separately installed Ollama and a suitable model. Model weights are not bundled. See the repository README for setup.

Save, move or restore

“Save a copy” exports one business. “Full backup” and “Restore backup” move the saved workspace between computers. Keep backups before changing or clearing your data.

Close or uninstall

Use Start → ShiftBrief → Close ShiftBrief before upgrading or uninstalling. Uninstall through Windows Installed apps. Saved business records remain in %LOCALAPPDATA%\ShiftBrief\data.

What Sarah does—and does not do

Sarah works with supported questions about saved records. Employee-departure and replacement suggestions require review. She does not decide whom to fire, automatically reassign shifts, or contact employees. This is not payroll software or legal advice.
