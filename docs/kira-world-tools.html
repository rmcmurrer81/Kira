Final legacy edition · Free Windows preview available

Kira Labs Voice Designer

Version 0.1.6 is the final planned version of Kira Labs Voice Designer. The earlier original-voice generator is being preserved as a free legacy tool for creators and programmers while Kira World moves toward separately researched voice technology. Evelyn’s approved original greeting is publicly playable, and Video Studio may continue using a preserved version of the older generator. No 0.1.7 or other new Voice Designer versions are planned. The available 0.1.6 EXE remains an unsigned experimental preview with untested graphical controls and no verified clean-PC installation.

A creative workflow, not just a voice model

Design it. Listen. Save your work.

Four functions envisioned for the free edition, with a straightforward local interface and clearly documented exports.

01

Describe a voice

Specify general vocal traits and make new original voice candidates rather than copying someone else's identity.

02

Listen and compare

Enter text, audition generated samples and choose the sound you want to keep. Final user-interface behavior still requires testing.

03

Save and export

Keep voice design profiles and export WAV audio for authorized creative, video, game or accessibility projects.

04

Use it independently

The planned tool will run separately from Evelyn and Kira World, with no companion memory or private resident data bundled.

What is verified: KiraWorld's Qwen3-TTS Voice Forge documents bounded local synthesis feasibility and audition artifacts. Its unsigned 0.1.6 preview installer has now passed backend generation and reinstall on one Windows test computer, but the new GUI and general release remain unqualified. The separate Local Voice Studio also has unfinished real-backend isolation requirements.

An installer that does the setup.

The current unsigned preview installer has provisioned its own Python, dependencies and local VoiceDesign model on one existing Windows computer. More hardware, clean-Windows installations, missing-runtime behavior and final release safeguards remain to be tested.

01

Check the computer — Windows version, architecture, available disk space, RAM and supported GPU/CPU route.

02

Download and verify — the selected model, exact software dependencies, permitted voice assets and license notices.

03

Install and test — first speech generation, WAV export, clean restart and an actual disconnected-computer test where offline use is promised.

For creators and programmers

Reuse the method. Understand the history.

Documentation, not guesswork

Alongside a future installer, Kira Labs intends to provide a getting-started guide, voice creation examples, WAV export instructions, hardware requirements and troubleshooting information. Developers should be able to understand what is reproducible and what remains experimental.

Chatterbox workflow guide

A separate guide will explain how Kira Labs used voice-generation assets with Chatterbox, distinguishing tested steps from experimental or unsupported integration. Compatibility will not be advertised unless the matching steps have been reproduced.

Any public edition will contain only rights-cleared models, code, licenses, and authorized generic or original examples. Evelyn's private voice, Synthetic Robert's recordings, protected Kira World voice profiles and other private reference packs are not part of a public release.

Archive policy and limitations · Final legacy version

Preserve the old tool. Develop the next voice system separately.

1.Finish Evelyn's voice

Approve and preserve her actual voice and demonstrate that her installed runtime can reproduce it.

2.Separate the old tool

Package only the public voice designer and its required files; keep private character voices and personal records out.

3.Audit the distribution

Review third-party rights and notices, dependency licensing, download integrity, local security and consent safeguards.

4.Pass release testing

Verify installation, output quality, restart behavior, supported hardware, offline behavior, uninstalling and accurate help instructions.

Final-version decision, October 25, 2026: Kira Labs will preserve and offer Voice Designer 0.1.6 as the final legacy edition. No later Voice Designer versions or feature upgrades are planned. The downloaded preview is already available; the checklist above explains why it must not be represented as a fully tested, signed or widely compatible release. Future virtual voice-box development is a separate Kira World research direction, not a promised Voice Designer 0.1.7. Private recordings and current supported uses of older voice components remain independent of the free download.
