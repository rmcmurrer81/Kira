3. Frozen context guard: mistakes reduced, qualification still failed

Read-only local comparisons used zero optimizer steps. Exact item sources: balanced original 60/320, binary 105/320, guarded 80/320; replay original 45/320, binary 120/320, guarded 85/320. Unrestricted binary introduced 16 and 57 newly wrong unsupported copies; the guard returned new wrong copies to zero. Guarded correct unknowns remained 1,044/1,408 balanced and 995/1,408 replay. An earlier correct replay abstention was lost. Neither guard qualified.

4. More restrictive affirmative source scope: smaller safer recoveries

Another distinct frozen zero-update readout raised exact item answers from 9/64 to 12/64 balanced and 1/64 to 7/64 replay, without newly wrong unsupported copies or loss of earlier correct answers relative to the original readers. But correct unknowns stayed at only 254/1,152 and 269/1,152. Only direct wording yielded new answers; supported questions with an aside remained at 2/32 and 0/32. No qualification.

5. Support-veto contrast prepared but not executed

The next author-created 608-case bank has 256 supported and 352 unsupported cases, balanced across anchor directions. Source-only rule and adapter fixtures passed. This phase made zero original model forwards and optimizer updates, so no held or cold model response scores exist yet. Reference-field answers must not be scored as learned reader answers.

Qualification, safety, and privacy boundaries

Tests involve synthetic typed evidence copying, abstention and source spans, not general dialogue, lifelong learning or deployed companions. No component, guard or checkpoint was adopted. Accepted Original12 remains 2/12, not rerun. Private source case text, local checkpoints, sensitive project files, likeness references, rejected images, or unlicensed media remain unpublished.
