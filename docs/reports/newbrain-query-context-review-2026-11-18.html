Familiar questions helped, but NewBrain still failed its complete learning gates

Two experimental arms continued the same full saved model and optimizer from step 18,704 to 20,752, with 2,048 real local GPU optimizer updates per arm (4,096 across arms). The primary curriculum substituted two familiar question templates for half of selected varied-binding slots; the control retained the original questions. Both used identical sampled indices, semantic targets and answer IDs. This does not isolate a single internal reasoning mechanism.

The primary scored known-template supported 19/32 versus matched control 13/32 (parent 6/32); known-template unsupported answers were 14/16 versus 8/16 control (parent 4/16). The predeclared narrow exploratory comparison passed. But the strict complete qualification failed: only one of eight frozen families passed, the family of already consumed teaching replies. No branch was adopted; accepted Original12 remains 2/12, not rerun.

Why the broader model did not qualify

Seven of eight frozen families failed. New query composition totaled only 8/32 curriculum versus 3/32 trained control and 10/32 original parent, indicating the new curriculum did not reliably transfer to unfamiliar query combinations. Canonical unknown answers declined to 29/32 versus 30/32 control, and complete canonical groups fell to 5/16 versus 7/16. Old binding controls reached 54/64, below a 64/64 requirement. Question length and answer position also changed within the bundled training comparison. Prior optimizer inputs had already exposed the individual fact bindings. No independent human qualification was performed.

Executed evidence and limits

Saved research results document both completed training streams and full checkpoints. A separate fresh process repeated each arm's 320 raw decisions byte-for-byte, including mistakes; a stored-artifact audit reported 620,167 scoped checks. These receipts indicate experimental reproducibility and limited artifact consistency, not useful independent learning or humanlike comprehension. This website review examines committed evidence; it does not rerun private GPU inference. All scored cases are consumed.

Separate software-only source-access checks

A distinct Windows long-path metadata-access B0 assembly completed real 269-character path checks and both normal and extended 147-test suites: 112 passed and 35 skipped per completed suite, with no failures. The preserved legacy run had 111 passed, 35 skipped and one expected AST-contract failure; timed-out attempts were not counted as passes. Both successor suites used the documented extended temporary-fixture policy, so not all normal I/O was proven. A later B1 metadata append has not been rerun against those tests. The separate software work does not improve the model's semantic learning score.

Public scope

Neither model replaces Qwen or powers a new autonomous person, body or voice. No new Original12 qualification was run: 2/12 remains the accepted baseline. Private raw prompts, training examples, model checkpoints, personal histories, local storage paths and unapproved media are excluded. Future validation would require independently frozen unfamiliar supported questions, correct abstention and preserved earlier answers.
