What was released

Original gameplay images captured from Kira Labs' own scripted games now appear in responsive four-game cards. Existing playable routes and tutorials are preserved. Visitors can choose gesture-triggered interface sounds and a browser-only explorer passport. The passport records game and lesson links opened from the lobby, not completed missions; no account or remote tracking is involved.

Verification and boundaries

The preview-capture source, first-party game screenshots and visual lobby code are committed. GitHub reports successful automated browser QA and successful GitHub Pages deployment for that release commit. There was no independent full-game playthrough, universal accessibility test or live Iris conversation in this release review.
