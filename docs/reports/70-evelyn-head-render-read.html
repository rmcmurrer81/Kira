Verified result

How the head test was performed
1. Freeze the implementation. The test used the reviewed compatibility-diffuse512 preset:
simplified diffuse materials with bounded texture sizes. The existing geometry and camera
crop were preserved.

2. Apply a fresh test gate. Other work tracks were held. Available RAM was checked before
launch against the unchanged 8 GiB startup floor, with a 3 GiB reserve rule. The owned head
process remained subject to its 4 GiB job limit.

3. Capture controls and three views. The test recorded an empty-scene control, then front,
three-quarter and side views at 800 x 800 pixels. It checked that the required object was
visible and that the views actually differed.

4. Check the original evidence. A separate saved-evidence audit verified the original PNG
provenance, pixel acceptance, compositor agreement and owned-process evidence. The
three accepted views had no recorded WebGL error or context loss.

5. Close the test. Browser, server and component cleanup were checked before the test
evidence and finite resource grants were closed. No test replay was used to replace a failed
original.

Measured scope
Foreground occupied approximately 17.9%, 18.6% and 22.2% of the three captured views. Pairwise
view differences were approximately 18.6%, 24.3% and 19.0%. Original-to-compositor disagreement
was 0% for each accepted view.

What this result does not establish
The test does not qualify the original physically based materials, continuous RAM availability, a
complete graphics-memory total, realistic skin mechanics, conversation, voice quality, lip
synchronization, persistent learning or an installer. Successful rendering alone is not a completed
Evelyn release.

NewBrain remains a separate primary research track. Original12 remains 2/12 and Qwen has not been
tested on that comparison. The latest diagnostic setup stopped before a model call; it produced no
new learning result.
