Matched clause verification exposes persistent name-binding failures

Two separate local CUDA comparisons failed their frozen gates. The declaration-verifier comparison completed 96 updates per arm but recovered 0/240 exact held ordered edges, 0/96 supported reports and 0/192 typed abstentions in each arm. The later matched clause-loss comparison completed 48 updates per arm but recovered 0/96 complete held name pairs in each arm.

Request-word comparison

A separate request-word trial completed 168 total CUDA updates: held request spans improved from 1/192 to 57/192, but supported answers remained 0/96 in both arms and held request roles remained 0/192. Both failed qualification; the read-only archived endpoint was not an adopted improvement.

Declaration verifier and read-only attribution

The factorized and ordered-pair arms each completed 96 updates from the same initialization. All 288 held documents returned format unavailable; that blanket abstention explains the lack of false reports. Neither arm found a usable threshold. A read-only attribution audit found 97/480 versus 100/480 complete edges in consumed fit examples but 0/240 in held wording, and both classified all 48 held mentions and denials as declarations by raw argmax.

Matched isolated clause loss

In the later isolated clause-loss comparison, exact alias spans were 4/96 and canonical spans 6/96 in each arm; both sides of matched reversals were correct on 0/48. Raw unrelated roles rose from 12/96 to 32/96, while raw request roles fell from 65/96 to 58/96. True assertion scores beat matched mentions on 48/48 versus 41/48 and denials on 30/48 versus 28/48. Neither arm found a usable calibration cutoff or classified any held role at the fixed 2.0 margin.

The production tokenizer reproduced 1,408/1,408 frozen clauses, and a separate gradient-only preflight passed five controlled checks without optimizer updates. The actual subsequent clause run completed 48 CUDA FP32 AdamW updates per arm; two independent scoring processes exactly reproduced the saved endpoints and raw scores. The earlier 96-update comparison also had exact cold replay.
