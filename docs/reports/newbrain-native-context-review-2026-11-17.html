Read-only diagnosis

A subsequent frozen-S3 NumPy CPU inspection made zero training updates. At 711/830 teacher-forced token positions, the reference token was the native top choice; nevertheless only 18/80 full greedy responses were correct. All 48 paired contexts had different measured internal states, while 36/48 pairs produced identical responses despite different required answers. This rules out literal state identity, not weak value binding or a particular causal mechanism.

Saved software-validation records report 118 repository tests run (84 passed, 34 skipped) and 18 diagnostic protocol/helper checks passed. These are engineering checks, not model-learning successes. The analysis did not preserve full logits or per-token hidden tensors for independent causal replay.
