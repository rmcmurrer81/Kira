Request-scope checks reduce false copies but still lose correct answers

Public aggregate review of committed summaries and manifests. The experiments recorded independent cold replays; this publishing review did not rerun model training or release private research assets.

Matched request-scope checks

Two scope heads each completed 128 FP32 updates on a local RTX 5060 Ti. The original decoder and field reader received zero updates. On fresh synthetic cases, the whole-question and request-clause checks reduced false copies but lost supported answers.

Both failed the frozen gate (at least 12/16 unsupported wordings, no more than 32/192 false copies, zero supported losses and exact restart). A supplied request-type control abstained on 192/192 out-of-scope cases and retained 54/96 fresh supported answers; that control did not infer request type. Cold replay reproduced the raw scores. A token-admission refusal was repaired before training by shortening auxiliary headers with the requests, records, order and budget preserved.

Separate Native decoder training: abstention, not recall

Two matched 192-update decoder arms using ordinary sequence loss versus a reciprocal fact-swap term produced 0/64 supported answers each, compared with 0/64 unchanged. Correct abstentions were 0/16 unchanged, 13/16 ordinary, 16/16 reciprocal. Complete fact swaps were 0/16 for each; new application recall was 0/4 and complete actual-history dialogues 0/8 for each. Earlier exact memory was 65/80 unchanged, 62/80 ordinary, 53/80 reciprocal. Both checkpoints reproduced saved responses on cold reload and failed qualification. A completed ordinary checkpoint was recovered without repeating training.

A separate earlier matched 192-update comparison adding ranking rather than reciprocal loss also had 0/64 supported answers and 0/16 complete swaps in each arm. Abstentions were 10/16 ordinary versus 5/16 ranking; original-format retention 0/80 versus 1/80 (unchanged 65/80). Bare-answer secondary scoring did not meet the frozen retention contract.

Isolated application memory candidate

A separate application-level repair distinguishes compound object labels rather than merging possessions with the same noun. Its synthetic identity checks improved from 6/9 to 9/9 and all seven earlier FactMemory regression tests passed. Results reproduced after cold restart and earlier package bytes remained exact. The candidate did not invoke or update Native and did not change the live application. These are narrow tested application behaviors, not learned neural recall.

Earlier question attention and source diagnostics

A matched question-order comparison (192 head updates each, frozen decoder) scored 234/576 supported for sorted versus 198/576 for preserved order; abstentions 264/384 versus 232/384. Neither answered both directions in any of eight ordered pairs. Both failed. A separate zero-update position probe showed that direction information could be detected in some token positions, without proving safe answer selection.

Another matched option-attention comparison (192 head updates each) improved quoted-pair accuracy from 1/10 to 3/10 and reduced quoted unsupported false copies from 36/216 to 18/216, while ordinary supported answers fell from 180/288 to 144/288. Plain unsupported false copies stayed 162/216; earlier previously correct cases lost were 178 and 200 on a separate 960-case retention bank. Neither qualified. A later zero-update scope diagnostic still failed to recognize any of eight fresh unsupported wordings; all four presentation/mask conditions produced 48/96 wrong unsupported copies per head. Correct abstentions from missing or ambiguous evidence did not prove recognized request scope.

Separately, adding a visible source-match feature to matched frozen-decoder heads changed supported scores from 12/128 to 14/128, but complete fact swaps fell from 1/32 to 0/32 and both scored 0/48 exact opposite-direction pairs. No adoption.

Limits

Synthetic single-turn results; scope and application tests are not learned recall or general dialogue. No model promoted; accepted Original12 remains 2/12, not rerun. These are distinct assistant-authored test banks with different denominators and are not a combined benchmark. No unrun proposal is represented as a result. No private prompts, individual records, code, media, checkpoints or restricted assets are published.
