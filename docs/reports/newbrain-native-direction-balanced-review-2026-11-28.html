NewBrain paired-direction trial rejected; balanced clause-loss engineering verified

Executed matched trial — qualification failed

A matched synthetic request-direction trial used 48 FP32 CUDA optimizer updates per arm with identical 96-case fitting schedules. The seeded baseline, ordinary cross-entropy and paired-direction arms each answered 0/32 supported prompts exactly and 0/16 supported pairs fully correctly. Both trained arms scored 8/16 on raw first-endpoint direction versus 0/16 at seed zero; all three scored 16/16 on raw last-endpoint direction.

All three endpoints returned empty outputs on 64/64 missing or uncertain prompts but gave 0/64 exact abstention reasons, retained 0/60 earlier supported cases and 36/36 earlier absent cases, and missed both historical veto cases (0/2). Independent cold readings reproduced all raw floats byte for byte. Neither arm qualified.

Verified CUDA implementation check

Before/after state matched exactly; zero optimizer updates. This is a one-batch implementation check, not a learning result.
