Separate second-record comparison

Each auxiliary arm completed 128 GPU updates, changing only the abstention score. One-record versus two-record exact supported answers were 20/128 versus 21/128; correct unsupported abstentions 159/256 versus 156/256; complete swaps 4/64 in both. Unchanged original supported accuracy was 21/128 and abstentions 160/256. This separate trial failed; no candidate was promoted.

Retrospective score diagnosis

In 16 of the 17 newly correct supported answers in the later scoped lookup trial, the control already ranked the correct ownership source first but abstained. The treatment answered 25 more supported questions (17 correctly) and 32 more unsupported questions (all incorrectly). Changing only the relative ownership-score gap yielded zero additional correct supported answers. These replays used consumed synthetic cases and no new model execution or training.

A separate second-record replay restricting saved candidates to two complete ownership values ranked correct candidates first in 47/64 forward and 51/64 reverse supported cases, but still yielded 0/64 and 27/64 exact answers after the original abstention score. It is a diagnostic using declared scope and source boundaries, not learned retrieval.

Per-record support prototype — untrained

A proposed reference score separates support for each record from copy preference. Fourteen fabricated checks passed; no tokenizer calls, model loads, decoder forwards or optimizer updates occurred. Future model testing is needed to establish whether the score distinguishes unique evidence from absence or ambiguity.

Limits and status
