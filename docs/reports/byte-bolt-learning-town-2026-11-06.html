Released scope

Byte & Bolt joins the Kira Labs Arcade as a fifth browser game with 22 distinct authored beginner programming and electronics projects: 14 fictional paid town service jobs and eight unpaid personal lab upgrades. Its stylized 3D town adds resident conversations, browser-local saves and finite mixed repeat practice. Existing four games remain. Game credits are fictional currency, not money paid to players.

Documented checks and limitations

The public release QA document records 59 passing Node regression groups (46 campaign/original, 13 scene) and a managed-browser continuation of an eight-project save through 14 newly added projects. GitHub confirms successful Arcade homepage browser QA and Pages deployment on November 7 UTC.

Unverified: guaranteed playtime, unlimited missions, real phone hardware WebGL behavior, offline local-file ZIP execution and independent pronunciation or audio compatibility on all devices. Lessons accept restricted return expressions, not arbitrary JavaScript; electronics exercises are simplified teaching models, not safety-certified hardware controllers. This release does not establish improved native NewBrain learning (accepted Original12 remains 2/12), a verified Evelyn likeness or working human anatomy.
