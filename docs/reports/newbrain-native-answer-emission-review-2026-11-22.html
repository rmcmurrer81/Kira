First-token observer versus unchanged decoder

A separate 240-forward read-only FP32 scan and CPU readback reproduced all top decisions. An observer requiring known query/source positions ranked the correct fact row first on 123/128 ordinary answerable cases: 62/64 forward and 61/64 reverse. Yet the decoder began 0/128 valid supported answers (also 0/16 unfamiliar supported prompts). Restricted row ranking does not establish that Native independently retrieves or generates the answer. There was no new training.

Controlled token-split ranking effect

A third read-only test made 192 FP32 GPU forwards over 96 matched assignment pairs. The evidence, query endpoints and other tokens stayed fixed while the query's token split differed. Independent CPU ranking matched.
