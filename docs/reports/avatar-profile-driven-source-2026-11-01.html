Kira World / Avatar Builder · November 1, 2026 · Experimental source and synthetic software fixtures

Profile-driven original body research

Source-level progress, not a completed avatar. The new generic compiler, reference-measurement software and host-dispatch code have not run a qualified native body-generation pipeline or produced an accepted original person. The October 31 connected-body and face rejections still stand. No organs, physiology or learned movement have been demonstrated.

What changed

  • Controllable original exterior fields. An initial region sampler was extended to a V2 profile with 68 explicitly supplied scalar controls. It can sample abstract torso, limb, palm, finger, thumb, heel, arch and toe geometry. Two-dimensional measurements can influence supported widths and lengths without copying reference mesh, rig or textures. These are numerical field samples, not a finished mesh.
  • Native meshing connection prepared. A NumPy field adapter and guarded native adapter connect to the existing owned meshing and neck-attachment functions. The new Core dispatch accepts an explicit profile request while preserving the previous path for older requests. It requires actual private authority, source-version bindings, inventory caps and an inactive candidate result. The entire native profile pipeline remains unrun.
  • Local reference guidance. An experimental two-dimensional reference module proposes ratios from pose landmarks and outer-silhouette masks, with explicit clothing, occlusion, view and uncertainty limits. Supported observations enter the same profile compiler. A bounded local worker has a candidate MediaPipe backend, but real image/video inference, model/decoder qualification and reference accuracy have not been tested here.
  • Privacy and identity boundaries. The source excludes private profiles, reference images, model assets, accepted personal identity data and body geometry. Host-side checks are intended to preserve the approved face, eye, voice and memory bindings, and to block secondary-body production until the primary body is genuinely qualified. These source checks do not establish deployment security.

What has been tested—and what has not

Small authored numeric and simulated fixtures exercise request validation, field-value changes, region/sample behavior, sole/digit support geometry, ordered neck contracts, provenance, local worker framing and explicit fail-closed dispatch. The dispatch package includes 20 small tests; the reference-measurement package includes 21 small tests. Those source fixtures intercept native building and use fake processes or synthetic observations. Test descriptions must not be mistaken for successful construction or photo reconstruction.

Not run or qualified: an actual full-scale NumPy volume and native meshing run through this new pipeline; real MediaPipe inference, video decoding and calibration; production interpreter/ABI and OS supervision; actual render/reload/export parity; accepted facial identity; rig, weights, UVs, materials and clothing; believable posed deformation; independently moving bodies; functioning internal anatomy or organs. No production body has been activated by this work.

Why it matters

This is a change in how Avatar Builder could eventually construct original, adjustable body shapes rather than relying on a fixed starting mesh. It also creates a safer boundary between reference-guided measurements, body-shape computation and the separate private approval process. The central remaining question is whether the pipeline can create a convincing, correctly connected original body from real reference guidance while preserving exact identity, privacy and render/export constraints.

Next meaningful checks

  1. Qualify private worker interpreters, package receipts, source bindings and operating-system limits, then run one authorized full native profile pipeline.
  2. Check exact head/neck attachment, actual mesh topology, contact surfaces, whole-scene budgets, Blender renders and GLB round-trips.
  3. Compare fixed front, side, rear and three-quarter views to authorized references, explicitly reject inaccurate head and anatomy results, and retain failures.
  4. Only after visual approval, test rigging, weighted skin, natural movement and possible motion transfer. Organs and physiology remain separate future research.

Evidence boundary: These are authored November 1 source changes in KiraWorld, not externally replicated research, an independently accepted human likeness, a working photo-to-3D service or a release announcement. Source packages and fixture results are separate from the earlier rejected October 31 body builds.
