# Circuitbound: The Lantern Siege

An original Kira Labs educational fantasy adventure. Open `index.html` through a web server, or play at https://kiralabs.org/arcade/circuitbound/.

The game uses plain HTML, CSS, JavaScript and Canvas, with 33 scenes, 10 guided coding and electronics puzzles, and four endings. Code answers are validated as text; arbitrary player JavaScript is never executed. Progress uses this game's own browser storage key.

The seven root runtime files and all 33 `voice/*.mp3` files belong together. There are no external runtime libraries, account requirements or installation steps. Narration starts after Begin; mute and replay controls are available. Scene narration is locally generated synthetic Sarah audio, used with the owner's authorization. Short puzzle feedback uses an available device voice. Written story text is always present.

The fictional power-supply puzzle teaches capacity and headroom; its example is not a universal hardware sizing rule. No physical wiring is required.

The complete beginner build tutorial (1 hour 33 minutes 39 seconds) is available at https://www.facebook.com/reel/1107715711870923. It covers the full game from a blank folder through testing. The source files in this directory are readable individually without a ZIP.

This is a separate game. Code Quest and the other existing Arcade games are unchanged.
