The flagship / an honest starting point

A synthetic person should not have to start over.

Identity, reviewed memory, voice and place are being developed as one connected system—not one interchangeable face over a chat window.

Working prototypes: local conversation, identity and reviewed memory records, voice experiments and a basic walkable Home World shell. The full embodied, persistent world remains in development.
