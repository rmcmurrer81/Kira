# Smaller, moving Chakra ecosystem — October 17 review
Public preview: https://kiralabs.org/chakra-previews/roz-moving-ecosystem-20261017/

Compared with the previous two-line contact preview, only the six-part ecosystem diagram's scale and motion have changed.

Based on the supplied original `Chakra_Consolidated_Refinements(1).zip`:
- original orbit function: six nodes rotate clockwise around the center once every 180 seconds while text stays upright;
- outer petal design rotates once every 140 seconds; inner petals once every 220 seconds in the opposite direction;
- center jewel rotates once every 90 seconds;
- the graphic shrinks from a maximum of 540px to 420px (22% smaller on desktop);
- narrow screens receive a smaller 320–365px layout without horizontal overflow;
- reduced-motion preferences disable this optional motion.

All six current labels, all other site copy and graphics, the Information Becomes entrance, the contact invitation and gold-orbit background, and the original slim footer are unchanged. Both the original version and this new version remain available. This is a website design preview, not a functioning ROSA application.
