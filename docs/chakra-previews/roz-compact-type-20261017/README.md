# Chakra review — smaller Information Readiness Gap fonts

Public preview: https://kiralabs.org/chakra-previews/roz-compact-type-20261017/

Based precisely on the Oct 17 “Kira Labs Font Version,” **not** the later illustrated project-card layout.

Only reduced typography in the Information Readiness Gap section:
- Five original bordered text boxes, identical wording and 3-over-2 grid
- Main headline roughly 20% smaller on desktop
- Introductory paragraph reduced to 16–21px
- Body inside cards reduced to 14px on desktop, 15px on small screens
- Card labels reduced to 10px and buttons to 16px
- Identical backgrounds, borders, colors and card placements

All other source files and content are byte-for-byte identical to the Oct 17 font preview. The “Information Becomes.” title fonts and particle animation, starfield, other sections, R/H/DI/CCE orbital animations, supporters, and contact design remain unchanged. This is a proposed review site, not the official Chakra site.
