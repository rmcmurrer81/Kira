Exactly one visual section was changed: the footer.

The old footer's single-line compact layout was replaced with the footer structure from Roz's original source ZIP / screenshot:
- Privacy Statement (opens the design preview's privacy page)
- Do Not Share My Information (opens an email to hello@chakra.io using Roz's original mailto URL)

- Back to top ↑ right-aligned link

The exact SVG icon designs were copied from the uploaded Chakra original website source. The first three social links in that source pointed to **generic platform homepages**, not verified Chakra profiles. In this design preview, those three remain visible but are intentionally non-clickable until Roz confirms her account URLs. The email icon is functional.

Desktop footer is a compact dark single line. Smaller devices display a wrapped or stacked layout for readability. The rest of the page, font choices, animations, section order, contact panel, and footer-adjacent content are unchanged.
