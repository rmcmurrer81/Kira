# Chakra font study — October 17

This is a **separate working preview**, based on the published animated seven-panel Chakra design.

**Comparison link:** https://kiralabs.org/chakra-previews/roz-kira-fonts-20261017/

Changes:
- Navigation, content, labels, buttons, dialogs and non-hero text use the **Inter** family and fallback stack used by kiralabs.org.
- Serif accents outside the hero use **Georgia**, as on Kira Labs.
- **Do not change** the "Information Becomes." header: "Information" stays **Outfit**, "Becomes." stays **Instrument Serif**.
- Existing hero positioning, particle-assembly sequence, drift and reveal timing, colors, mobile behavior and starfield are inherited unchanged.
- Existing R, H, DI and CCE orbit-line and glowing-dot animations, letter positioning, contact section and all other content are inherited unchanged.
- Reduced-motion settings remain available.

Only index.html was minimally modified to load kira-typography.css. All other source files are byte-for-byte copied from the animated seven-panel version, with no changes to JavaScript, content, or animation CSS.

Public review materials are conceptual; ROSA products are not presented as operational enterprise tools.
