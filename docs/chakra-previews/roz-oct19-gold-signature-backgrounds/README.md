Based on Roz's email “Website Update???” and the Gold Signature Proposed Site.
The first five site sections are the opening hero, Company, Information Gap,
Consequences and animated Ecosystem. The fifth (#ecosystem, Ferris wheel)
already has an approved background and has NOT been changed.

Changes to the other four backgrounds, based directly on the Gold Signature
design concept:
- Opening: warm charcoal / amber atmospheric gradient, gold stars.
- Company: #10131c.
- Information Gap: #090c16.
- Consequences (corresponds to Gold Signature "Boundary"): #121014,
  with a subtle warm gold haze.

The existing canvas-based starfield in motion.js was recolored warm gold
because it paints an opaque dark-blue background over the CSS layer.
No changes to the original "Information" pixel-particle letter reveal.
Only the "Becomes." entrance uses a stronger sweeping/tilting motion and
returns to the same exact final position. Reduced-motion support remains.

All existing words, cards, compact designs, buttons, links, page order,
resting typography, Ferris-wheel page and motion, and later pages
(including Technologies, Dimensions, Supporters and Contact) are identical.
This is a separate nonproduction design preview. Source preserved.
