# Chakra full website preview — centered Information Becomes bridge

Review: https://kiralabs.org/chakra-previews/roz-oct18-gold-information-bridge/

This is a separate full-site review copy of the October 18 Chakra presentation
preview with Kira Labs gold accents, based on:
https://kiralabs.org/chakra-previews/roz-oct18-gold-clean-headings/

The changes requested on October 18, 2026 are limited to the consequences cards:
- Move **INFORMATION BECOMES** from the right card to a centered, horizontal-rule
  bridge above the two consequence cards.
- Keep **BUSINESS CONSEQUENCES** in the left card and **HUMAN REALITY** in the right.
- Capitalize and italicize the two labels so each reads *Can include:*.

Everything else is preserved from the complete source preview: all other text
and sections, Kira Labs gold styling (#ffc86a), backgrounds, animated ecosystem,
navigation, interactions, logos, privacy page, and responsive behavior.
The original and intermediate previews have not been modified.

This is a nonproduction design study; it does not represent an operational product.
