# Chakra design previews

Seven concept website variants prepared for Roz. These files are public at `https://kiralabs.org/chakra-previews/` by request. They are **design studies, not production Chakra websites**, and must not be interpreted as functioning ROSA or HCI MVPs.

- The two restrained concepts are `quiet-gold` and `quiet-cyan-gold`.
- The other five designs are copies of earlier private review previews.
- The rest of the Kira Labs website is untouched.
- Each page uses `meta name="robots" content="noindex,nofollow"` as a request to search engines, not as an access-control system.
- These URLs are publicly accessible, and anyone with them can view them.

For an official Chakra launch, Roz should approve content, brand identity, product claims and contact information.
