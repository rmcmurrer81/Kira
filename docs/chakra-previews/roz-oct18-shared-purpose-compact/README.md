# Chakra full website — compact unnumbered technology cards

Review: https://kiralabs.org/chakra-previews/roz-oct18-shared-purpose-compact/

Source: https://kiralabs.org/chakra-previews/roz-oct18-shared-purpose-technology-cards/

Roz's "One Shared Purpose" technology section has been adjusted for review:
- Remove the four card prefix numbers and separating slashes; only ROSA, HCI, DI, RIT remain as eyebrow labels.
- Reduce desktop heading, card height, card artwork, type, buttons, padding and gaps.
- At desktop widths (941px and larger) the design targets showing all four cards and the heading on one screen, including typical laptop/desktop viewports. Very small desktop browser heights or unusually high zoom may still need scrolling.
- Tablets/phones stack cards as needed to avoid cutting off content.

The new `shared-purpose-compact.css` is linked after all prior stylesheets.
The existing, working RIT/ROSA/HCI/DI modal interactions remain.
All other full-site sections, orange-gold glow, six-node animation,
contact/privacy pages, and prior text changes are untouched.
Previous previews are preserved; this is a nonproduction visual review.
