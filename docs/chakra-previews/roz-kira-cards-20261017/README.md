# Chakra Information Gap — Kira Labs project-card design

This new preview copies the October 17 Chakra Kira-font variant with its hero and animation completely unchanged. Only the Information Gap section has been redesigned to use Kira Labs-style project cards, illustrative SVG covers, thin borders, compact status labels, 23px headings and **14px Inter descriptions**. All five original paragraphs remain intact. On wide desktop the grid has four columns, then three, two, and one as the screen gets smaller. The original sections after Information Gap, ROSA product visuals, and the rotating orbit effects are copied unchanged.
