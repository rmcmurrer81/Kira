Development status / October 2026

A demonstration being built—not a finished download.

The current development reports describe Evelyn as a separate Qwen-based AI and technology historian in progress. A historical Kira conversation test harness has been located for adaptation, but Evelyn's own installer, generated dialogue, voice, speech-synchronized lip movement, memory persistence and repeated conversation tests are not yet confirmed as successfully completed. A separate controlled eyelid blink has passed.

October 19 development update: Visitor-specific application-memory namespaces and reusable detailed head controls are being added. A frozen 14-turn test with three synthetic visitors is prepared to check delayed recall, restart persistence, visitor separation, unknown visitors and a corrected preference. The test is not yet executed. Live recall, audio, geometry and clean installation remain unverified; saved application memory is not proof of neural learning. Documented limits ↗

October 20 head-preview milestone: A newer local compatibility-render test now shows Evelyn’s licensed 3D head candidate from distinct front, three-quarter, and side angles. Developer screenshots report that all three visible saved views passed blank-screen checks and matched their direct canvas captures. The preview uses modified diffuse materials and reduced textures; the original PBR appearance remains unqualified. The controlled eyelid test is now verified; speaking, synchronized lip movement, generated conversation, visitor memory after restart, and a public installer remain unverified. The earlier failed-render evidence remains archived. Read the October 20 milestone → Browse reports and source images →

Evelyn Hart and Avatar Builder · October 23, 2026 · Independently reviewed source

Her body, library and original voice move closer to testing.
Source review is not a completed demonstration.

Three new engineering steps passed their described independent and primary source-code reviews. None supplies new live conversation audio, a naturally moving full body, or an installer ready for public download.

01 / BODY AUTHORING

163-bone export checks

A checked design now maps 25 joint chains to a canonical 163-bone rig and 139 skin-weight groups. The export auditor compares the package, build report, vertex reference, GLB, Blend and rig-rest files. It verifies declared joint/hierarchy, rest-transform and sampled skin data—not natural deformation, full anatomy, realistic clothes or physical motion. The new export execution gates remain disabled.

02 / DOCUMENT LIBRARY

Document-import fixes reviewed

The app now has reviewed source fixes for preserving a selected library destination and a supplied document title/date while recursive discovery is in progress. The staged ordinary-file library remains 30 publications plus two original AI/film-technology primers. These are files in preparation, not material Evelyn has actually read. Installation, import, page-reading and restart behavior still need runtime tests.

03 / ORIGINAL VOICE

Audition and recording adapter prepared

A new source-reviewed adapter retains Evelyn's original adult female voice design, 55-word audition text, profile and seed. The planned test records before generation and plays the generated voice through admitted physical speakers while retaining receipts. The staged app's 28-file mapping was reviewed. No unique voice has yet been generated, played, recorded or approved.

Not yet established: human-audible speech, live visitor conversations, full internal anatomy, accepted natural movement, fabric motion, installer operation, or an exported body copied and verified in Patient Horizon. Failed and partial future recordings remain part of the planned review. Private books, reference media and visitor memories are not published.

Evelyn Hart · October 23, 2026 · Verified preparation / pending release tests

Release documents prepared.
Actual installation and movement tests still ahead.

The latest repository review records a two-page release-requirements document and a four-page installation and troubleshooting guide. All six PDF pages were visually inspected, and the prepared PDF, text and HTML materials were checked against copies in the university review folder. This is a documentation milestone, not a public installer, published end-user guide or confirmation that Evelyn can run on another computer.

01 / RELEASE DOCUMENTATION

Requirements and support guides

The documents explain planned signed updates, protected starting identity, developing memories, owner-controlled data, an editable local library, and practical help for installation, documents, voice and recovery. Before public distribution, the guide must be matched to the tested installer and bundled offline as well as placed beside the official download.

02 / MOVEMENT SOURCE

Blended poses and breathing timing

Reviewed body-motion source now combines rest-relative movements with blended poses and carries breathing timing between movement routes. Static review passed; full-body export parity, recorded natural walking, reaching, clothing movement and unseen body variants have not passed runtime testing.

03 / ORIGINAL VOICE

More reliable audition preparation

The original-voice execution bridge has a reviewed change to retain real process handles before potentially failing setup steps. Evelyn's voice will be selected from a newly generated original adult female design suitable for her young-adult character. No original audio, qualified physical playback, recorded conversation or final voice approval exists yet.

Release boundary: signed installation, tested hardware requirements, backup/restore, book discovery, privacy behavior, original voice, natural movement and third-party clean installation still need validation. The full four-page guide remains a pre-release draft. A public troubleshooting topic preview and a separate release-requirements roadmap are available, but neither is a tested installer manual or a download. October 23 document review →
