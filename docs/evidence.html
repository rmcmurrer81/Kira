October 25, 2026 · NewBrain · Five-world learning and retention comparison

Old-answer retention improved.
New-question composition declined.

In a narrow five-world synthetic learner, balanced replay preserved 38/40 old answers versus 14/40 under blocked training, but answered fewer held-out question-form cases (7/20 versus 12/20). Both primary arms acquired 13/20 new answers and failed 0/10 unseen abstention cases. All fifteen saved branch states reproduced their 270 complete answers in a separate process.

Saved-data review checked receipt chains for 35,840 updates, but this is neither an independent external training rerun nor an accepted Original12 improvement. The main reference stays 2/12; these are five descriptive seed/world pairs, not a general intelligence benchmark.

NewBrain · Independently reviewed operating-system diagnostic · October 21, 2026

Historical failure, now superseded: the corrected launch subsequently passed the fixed 26 compatibility checks. The measurements below describe the earlier failed test only.

A precise limit mismatch.
No new learning score.

A controlled Windows process-owner check requested 858,993,459 bytes for both process and job memory, but reported 858,992,640 bytes for each: exactly 819 bytes below the request. Returned structure size, flags, process-limit and CPU-affinity values matched. The strict validator rejected the difference before any child process was created; none of 26 compatibility cases ran.

Measured · Original runtime and independent saved review

819-byte readback difference

Both memory limits were lower by 819 bytes. Handles were closed, but complete process-family cleanup is not established by this check. This was not a RAM-exhaustion or training-quality measurement.

Interpretation · Not yet proved

Possible page normalization

The observed numbers fit a plausible whole-page rounding explanation. The host Windows page size was not queried in the measured run, so the mechanism remains a hypothesis.

Reviewed next implementation · Runtime pending

Preserve the resource safeguards

A source-reviewed correction queries system page size, chooses a whole-page cap not exceeding the policy limit and retains exact memory readback. Its runtime test is still outstanding.

Scientific results unchanged: accepted Original12 2/12; a separately preserved failed 0/12 trained state; a separate rehearsed 3/3 after restart study; and no Qwen benchmark comparison. These should not be combined into a new success claim.
