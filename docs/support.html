First published target

More system-memory headroom

The September 8 notes name a matched 64 GB kit (2 × 32 GB) as the next target after a local motion test stopped at memory admission.

Confirm the need and exact kit with Robert before buying anything. More RAM does not fix software errors.

Later / benchmark first

VRAM, VR and shared capacity

Larger GPU memory, VR equipment and servers are longer-term possibilities. They require measured workload needs, world readiness and compatibility testing.

No GPU purchase, headset support list, server count or guaranteed latency is established.
