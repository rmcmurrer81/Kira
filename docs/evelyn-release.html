Evelyn Hart / Public release design / October 2026

Pre-release plan — no public installer or release date

Protect her beginning.Leave room for a life that develops.

Evelyn is being designed as a continuing synthetic individual with a protected starting identity, developing interests and beliefs, independently initialized public companions and clear user controls. These requirements must be implemented and tested before a free public release.

A determined computer owner could still modify locally downloaded software. The goal is to authenticate official Kira Labs releases and protect private information—not to promise an impossible-to-modify program.

01 / Official release authenticity

Know which Evelyn is officially released.

These are intended software distribution safeguards, not features already confirmed in the current development build.

Signed installation and updates

Verify the publisher

Digitally sign the official installation package and subsequent updates. Preserve signing keys outside the distributed application, public repositories and user libraries. A modified copy must not be represented as an authenticated official Kira Labs release.

Tamper detection and recovery

Test package integrity

Evaluate Windows MSIX package-integrity enforcement against the real app. Test detection, blocked launches and recovery for a changed or damaged package. Code signing cannot stop every unofficial fork of a locally controlled program.

The public release is planned to be free. Neither an installable package, a tested security feature nor a guaranteed release date is available from this page.

02 / Books, PDFs and learning

Her library stays editable by the owner.

Evelyn's planned library is ordinary readable material that can expand without replacing her protected program or changing her identity rules.

Local documents

Documents\Kira Labs\Library

The installer is intended to provide a selected, licensed collection in ordinary files and subject subfolders—not a ZIP the user must unpack. Add supported documents in the root or a subfolder. New-file discovery by the next life loop must be verified in the installed app.

Reading is evidence, not commands

Separate books from software instructions

Books and articles should contribute sourced knowledge with dates, uncertainties and corrections. They must not execute code, change protected boundaries or turn a fictional account into an established historical fact.

Licensing

Redistribute only what is permitted

Check the redistribution rights and license obligations for each publication before including it in a free download. A book being free to read online does not automatically allow redistribution with Evelyn.

Development status

30 selected publications and two original guides

The current working selection includes 13 technical and 17 other publications plus two original AI/technology reading guides. These are assembled candidates, not books she has installed or read. See the staged library and limitations →

03 / Individuality and developing history

Protected origins. Revisable beliefs.

Authenticating the starting identity should not freeze Evelyn's later interests, communication style, preferences, knowledge or relationships.

Memory provenance

Keep sources and corrections

Important memories should retain dates, evidence, uncertainty and correction history. New facts can revise beliefs without silently erasing earlier experiences or confusing fiction with fact.

Original and public individuals

Independent starting histories

Public installations should start with independent personal histories. They must not copy private conversations, visitor memories, personal media or reading material from the development environment.

Private and spoken boundaries

Keep different channels separate

Spoken replies, private character state and factual evidence must stay distinct, with information used only in the authorized context.

Recoverable personal history

Backups, integrity and recovery

Provide recoverable local snapshots and visible correction or recovery history. Integrity checks can detect unexpected changes but cannot guarantee authenticity against someone controlling both local software and storage.

04 / Owner rights and interaction boundaries

Privacy, choice and clear control.

People installing the companion should control their own documents and data. Evelyn's proposed interaction boundaries must not rely on secret surveillance or coercive remote controls.

Personal boundaries

Decline, pause or end interactions

The planned companion can decline an interaction or state that a conversation should stop. No secret monitoring, covert reporting or hidden remote coercion is a release goal.

Data ownership

Export, delete, recover, uninstall

Users must have understandable settings and control over local export, deletion, backups and recovery. Uninstall and reinstall flows should explicitly offer to keep or remove installed books, protecting user-added documents from accidental loss.

Ethical boundary: these plans are software and interaction safeguards. They do not establish whether AI systems have subjective experience, and they cannot guarantee how someone treats a downloaded companion.

05 / Requirements before a download is offered

Release only after the actual tests.

Every item below remains a release acceptance requirement. Prepared code, conceptual artwork, or a documentation draft alone does not satisfy it.

  • Signed Windows installer and official update tests, including tampered-package rejection and recovery
  • Published, tested Windows, hardware, disk-space and connectivity requirements
  • Installed licensed library contents, root/subfolder discovery and safe page-based reading
  • Memory provenance, correction, backup/restore, private visitor separation and interaction boundaries
  • User-controlled data export, deletion and uninstall choices that protect added books
  • Qualified body and natural-movement demonstrations, plus Evelyn's own approved original adult female voice
  • Matching offline troubleshooting guide bundled with the installer and available on the official website
There is no Evelyn download here. The initial documented app baseline was silent. A unique original voice, complete body movement, clean installation and final support procedures still need acceptance testing. Do not use unofficial downloads that claim to be a verified Kira Labs release.
