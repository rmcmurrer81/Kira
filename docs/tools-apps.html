06 / Synthetic workstation

Aster

Early foundation · private

Aster Workstation is a local-first identity, memory, workspace and job foundation intended to use NewBrain. Real autonomous conversation remains unavailable; experimental learning studies have retained negative results.

  • Identity and local memory foundations
  • Reviewable jobs and workspace state
  • No qualified NewBrain dialogue yet

08 / Final legacy voice tool

Voice Designer

Final 0.1.6 · unsigned preview

Voice Designer 0.1.6 is the last planned version of this older voice generator, preserved as a free unsigned developer preview. Backend generation and reinstall passed on one Windows host; the GUI and clean-PC use remain unverified. No further versions are planned.

  • Original-voice design goals
  • Preview setup tested on one host
  • Hardware and troubleshooting drafts
