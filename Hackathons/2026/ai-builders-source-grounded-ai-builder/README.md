# Kira Labs Source-Grounded AI Builder

**Hackathon:** AI Builders Hackathon  
**Mode:** Solo  
**Status:** Pre-build specification only. Implementation must begin during the official August 21–25, 2026 build window.

## One-sentence idea

A standalone creation studio that builds source-grounded Expert, Historical, Fictional, and Original AI candidates, then gives the user a review package before chat, voice, avatar, or activation is allowed.

## Why this is not a copy of private Kira World

The public project will recreate the idea with fresh code, synthetic examples, original assets, and no private Kira World profiles, memories, source packs, voices, body files, or internal tools. The old system informs the product requirements; it is not copied into the submission.

## Solo MVP

1. Choose candidate type: Expert, Historical, Fictional, or Original.
2. Enter the expertise, person, character, version, era, or canon point.
3. Add reviewed sources or an original-creation brief.
4. Separate source facts, interpretations, and unknowns.
5. Generate a candidate package with a normal name and separate role title.
6. Choose body mode: no body, simple original avatar request, or future avatar.
7. Choose voice mode: text only, original synthetic voice plan, or clearly labeled approximation.
8. Review unresolved questions and approve or reject activation.
9. Open a bounded chat that cites the approved source cards and says “unknown” when sources do not support an answer.

No application code, final repository, hosted demo, or generated candidate package should be created before the official hackathon build window begins. This folder contains planning documents only.
