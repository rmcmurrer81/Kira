# Kira Embodiment Sandbox

**Hackathon:** AI Builders Hackathon  
**Mode:** Solo  
**Current status:** Planning only. Do not add implementation before the official build window shown in the participant dashboard.

## Concept

A browser-based three-dimensional room for testing safe embodied-agent behavior before connecting an agent to a physical robot.

## Solo MVP

- A simple virtual room and generic robot marker
- Simulated distance, obstacle, door, battery, and human-location inputs
- Stop-before-collision behavior
- Ask-before-entering-private-space behavior
- Explain why movement stopped
- Keyboard and low-motion controls
- Append-only decision log

## Purpose for Kira World

This teaches world coordinates, collision detection, sensor interpretation, human–robot interaction, and future WebXR design without claiming that Kira already has a finished physical body.
