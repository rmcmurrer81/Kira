# Kira Storyworld Continuity Agent

**Hackathon:** Agentic Cinema — The Blockbuster Hackathon  
**Mode:** Solo, online  
**Purpose:** Help an independent creator keep an original script, story bible, production plan, and fan-facing canon consistent.

## Solo MVP

- Parse a small original story bible and five-page original script.
- Track when each character learns important information.
- Flag a character using knowledge before learning it.
- Track props and locations across scenes.
- Generate a production checklist.
- Answer fan questions only from approved canon and return `unknown` when unsupported.

## Starter

`app.py` is a deterministic continuity checker using an original synthetic example.

```bash
python app.py --self-test
python app.py
```
