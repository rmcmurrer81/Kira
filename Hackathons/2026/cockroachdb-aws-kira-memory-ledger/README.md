# Kira Memory Ledger

**Hackathon:** CockroachDB × AWS — Build with Agentic Memory  
**Mode:** Solo concept  
**Priority:** Planning-only unless explicitly reprioritized before the deadline.

## Concept

A persistent memory ledger that stores currentness, provenance, correction history, semantic retrieval data, and revocable sharing decisions.

## Required final architecture

- CockroachDB as the persistent memory layer
- At least two required CockroachDB tools, such as Distributed Vector Indexing plus the managed MCP server
- At least one AWS service, such as Bedrock, Lambda, or S3
- Public open-source repository and functioning hosted demo

## Why it is paused

The deadline is extremely close to the August 15 Codex credit refresh. A rushed deployment would risk false sponsor-integration claims and weak testing. Preserve the architecture for a later memory-focused event unless Robert explicitly chooses to make this the top priority.
