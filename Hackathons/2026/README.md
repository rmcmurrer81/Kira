# Kira Labs Hackathon Incubator — 2026

This branch is a **safe public incubator**, not the private Kira World runtime and not yet the final repository for any Devpost submission.

It creates one clearly separated folder for each hackathon Robert registered for on August 10, 2026. Each folder contains a project concept, a solo-sized MVP, sponsor-integration notes, honesty boundaries, and—where the contest window and rules allow it—a small deterministic starter prototype.

## Non-negotiable boundaries

Read `COMMON_BOUNDARIES.md` before moving code into a final submission repository.

- No private Kira memories, conversations, body files, voice files, medical anatomy files, tickets, email, identity documents, or credentials.
- No copyrighted Power Rangers, Miraculous, film, television, poster, song, or script material.
- All demonstrations use synthetic or original data.
- Each final submission will be split into its own repository if the event requires a dedicated public open-source repository.
- Sponsor SDKs are added only after the exact event rules and build window are confirmed.
- AI-assisted development is disclosed honestly.
